# Studio study brief

Develop a concrete creative project that can be prototyped with ordinary studio tools. Favor a clear visitor experience, material specificity, and a testable artistic claim over technical spectacle. Account for accessibility, maintenance, heat, sound, and the difference between an evocative description and something that can actually be built.

Edit this file before running: add the subject, space, available materials, budget, schedule, audience, and any non-negotiable constraints.
